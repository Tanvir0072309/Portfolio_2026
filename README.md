##  Features

A modern, responsive, and interactive portfolio website built to showcase my web development projects, technical skills, and experience as a Full-Stack Developer. 

Built with clean UI/UX practices, modern CSS layouts, interactive 3D assets, and mobile-first responsiveness.


##  Built With

- **HTML5 & CSS3:** Semantic markup, CSS Grid/Flexbox, dynamic variables, and custom theme modes.
- **JavaScript (ES6+):** Dynamic project toggles, theme switching, and automated asset track animations.
- **Google Model-Viewer:** Lightweight web component for rendering 3D GLB models seamlessly.
- **Google Fonts & SVGs:** Modern typography (*Space Grotesk*, *Inter*, *JetBrains Mono*) and vector icons.
